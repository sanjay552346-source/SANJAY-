
Requirement Analysis Phase

Functional Requirements:

- User can enter a story idea or theme.
- App can generate a comic story using AI.
- App can create characters for the comic story.
- App can generate dialogues for characters.
- App displays the generated comic story clearly on the screen.
- User can create different stories based on their ideas.

Non-Functional Requirements:

- Fast story generation.
- Simple and easy-to-use interface.
- Works on both mobile and desktop browsers.
- Provides creative and relevant story content.

Tools & Technologies Required:

- Google Gemini API
- Google AI Studio (for development)
- GitHub (for version control and submission)
